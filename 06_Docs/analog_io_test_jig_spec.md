# 🛠️ 아날로그 입출력 테스트 지그 회로 설계 사양서 (Analog IO Test Jig)

이 문서는 수소 제어 보드(H2_Control_Board)의 0~5V 아날로그 입력(AI) 및 아날로그 출력(AO) 포트의 정상 동작 여부를 빠르고 직관적으로 검증하기 위한 보조 테스트 지그(Test Jig)의 회로 설계 가이드라인을 정의합니다.

---

## 1. 시스템 개념 블록도

```mermaid
graph LR
    subgraph Test Jig (지그 보드)
        5V_SYS[5V 전원 소스] --> POT[가변저항 10kΩ]
        POT --> OPAMP[Op-Amp 버퍼 LM358]
        FND_VM[미니 FND 전압계]
        TP_OUT[출력 모니터링 TP]
    end

    subgraph Main Control Board (메인 제어 보드)
        MCU_ADC[MCU ADC 입력단]
        MCU_DAC[MCU DAC / PWM 필터 출력단]
    end

    %% 테스트 1: 가변 전압 인가
    OPAMP -->|0 ~ 5V 가변 신호 송출| MCU_ADC

    %% 테스트 2: 제어 보드 출력 모니터링
    MCU_DAC -->|0 ~ 5V 아날로그 출력 송신| FND_VM
    MCU_DAC -->|오차 측정용 단자| TP_OUT
```

---

## 2. 세부 회로 설계 규격

### 2.1 아날로그 입력(AI) 테스트 회로 (지그 -> 메인 보드)
지그에서 메인 보드의 아날로그 입력 단자로 0~5V의 정확하고 노이즈 없는 가변 전압을 인가하기 위한 설계입니다.

1. **가변저항 (Potentiometer) 선정**:
   - 값: **`10kΩ`** (정밀 사양인 멀티턴 가변저항 권장 - 미세 조정 용이).
   - 결선: 1번 핀 -> `5V`, 3번 핀 -> `GND`, 2번 핀(Wiper) -> Op-Amp 비반전 입력(IN+).
2. **볼티지 팔로워 (Voltage Follower / Unity Gain Buffer) 구성**:
   - 가변저항 출력 전압을 보드의 ADC 단자로 직접 넣으면, 메인 보드의 입력 임피던스와 전류 흡수로 인해 전압 드롭(왜곡)이 발생합니다.
   - **Op-Amp 단일 전원 소자 (LM358 또는 LMV358 Rail-to-Rail)**를 사용하여 전압 추종기 회로를 구성합니다.
     - **IN+ (비반전 입력)**: 가변저항 2번 Wiper 핀 연결.
     - **IN- (반전 입력) & OUT (출력)**: 두 핀을 쇼트하여 피드백 구성 (Gain = 1).
     - **VCC/GND**: 지그의 5V 및 그라운드 공급.
   - 이 버퍼를 거친 Op-Amp `OUT` 노드를 메인 보드의 아날로그 입력 커넥터 핀으로 다이렉트 송출합니다.
3. **일차 필터링**:
   - Op-Amp 출력단에 직렬로 **`100Ω` 댐핑 저항**을 연결하고, 그 뒤에 **`10nF` 바이패스 커패시터**를 그라운드로 묶어 출력 서지 노이즈를 억제합니다.

### 2.2 아날로그 출력(AO) 모니터링 회로 (메인 보드 -> 지그)
메인 보드에서 출력하는 0~5V 아날로그 전압 신호가 설계값과 일치하게 출력되는지 지그 상에서 검측하기 위한 설계입니다.

1. **디지털 FND 전압계 모듈 연동**:
   - 시중의 **3선식 초소형 LED FND 전압계 모듈 (측정 범위: 0~30V)**을 지그 보드 상에 다이렉트 실장합니다.
     - **적색 선 (VCC)**: 지그의 `5V` 상시 전원 연결 (전압계 스펙에 맞춤).
     - **흑색 선 (GND)**: 지그의 `GND` 연결.
     - **황색/백색 선 (VIN, 측정선)**: 메인 보드에서 넘어오는 아날로그 출력(AO) 단자에 다이렉트 연결.
   - 이를 통해 멀티미터를 매번 연결하지 않고도 FND 세그먼트를 통해 실시간 출력 전압(예: `3.30V`, `4.52V` 등)을 소수점 둘째 자리까지 즉시 파악할 수 있습니다.
2. **정밀 테스트 포인트 (TP - Test Point) 루프 배치**:
   - 전압계 모듈의 자체 오차를 방지하고 오실로스코프나 멀티미터로 정밀 계측을 병행할 수 있도록, 입력 노드에 금속 핀 헤더나 케이블 고리형 테스트 포인트(TP)를 병렬 배치합니다.
3. **과전압 입력 보호단 (OVP) 설계**:
   - 메인 보드 측의 회로 결함이나 쇼트로 인해 테스트 입력단에 5V 이상의 고전압(예: 12V나 24V)이 유입되는 경우를 대비합니다.
   - 측정 입력 노드와 GND 사이에 **`5.1V 제너 다이오드 (Zener Diode)`**와 **`100Ω ~ 1kΩ` 직렬 댐핑 저항**을 배치하여 지그 전압계 모듈 및 내부 소자를 영구 파손으로부터 안전하게 보호합니다.
